This page exists to prove the chat widget works on a site that knows nothing about Desker. It has its own styles, its own markup, and no framework. The bubble in the corner is the entire integration.

Open this page with ?agent=AGENT_ID to load a published agent — copy the id from the agent's Share with clients panel. Add &origin=https://your-host to point the widget at a Desker server on a different origin.

In a real integration you would paste the fixed snippet from that panel instead; the query parameters here only exist so one demo page can be pointed at any agent.
